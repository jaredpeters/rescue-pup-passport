# Changelog

## 0.1.0 (2026-11-16)

First tagged release.

- Per-dog records: profile, weight, feeding, potty log, health timeline, milestones, daily notes, vet checklists and stories
- Multiple dogs, with a switcher at the top of the page
- Adopter report: a printable summary for the adopting family
- JSON export and import, and CSV import of vet records
- Static export, so it runs on any static host; data lives in each user's own Supabase project
- Setup guides for first-time users, and a guide to contributing with an AI assistant
